# Archive des passations

Chaque passation remplacée dans `HANDOFF.md` est archivée ici avant d'être
écrasée, nommée `AAAA-MM-JJ-sujet-court.md`. Ne jamais écraser une fiche déjà
archivée.

L'index de ces fiches est le tableau « Historique des passations », en bas de
[`HANDOFF.md`](../../HANDOFF.md).
